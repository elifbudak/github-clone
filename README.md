<h1 align="center">🎨 GitHub UI Clone</h1>

<p align="center">
GitHub arayüzünden ilham alınarak geliştirilmiş,
SCSS mimarisi kullanılarak oluşturulmuş
modern ve responsive bir <strong>GitHub Interface Clone</strong> çalışmasıdır.
</p>

<hr>

<h2>📌 Proje Amacı</h2>

<p>
Bu proje, modern web arayüzlerinin nasıl tasarlandığını anlamak
ve GitHub platformunun kullanıcı arayüzünü klonlayarak
frontend geliştirme pratiği yapmak amacıyla hazırlanmıştır.
</p>

<ul>
<li>💻 GitHub tarzı arayüz tasarımı</li>
<li>📐 Modern layout yapısı</li>
<li>📱 Responsive tasarım</li>
<li>🎨 SCSS ile modüler stil yönetimi</li>
<li>⚡ Temiz ve sürdürülebilir kod yapısı</li>
<li>🧩 Flexbox ve Grid kullanımı</li>
</ul>

<hr>

<h2>🛠 Kullanılan Teknolojiler</h2>

<ul>
<li>HTML5 (Semantic Structure)</li>
<li>CSS3</li>
<li>SCSS (Sass Preprocessor)</li>
<li>Flexbox</li>
<li>CSS Grid</li>
<li>Responsive Design</li>
</ul>

<hr>

<h2>✨ Öne Çıkan Özellikler</h2>

<ul>
<li>SCSS ile modüler stil yapısı</li>
<li>Component bazlı stil organizasyonu</li>
<li>Modern layout teknikleri</li>
<li>Responsive tasarım yaklaşımı</li>
<li>Temiz ve okunabilir frontend mimarisi</li>
</ul>
